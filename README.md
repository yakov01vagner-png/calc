# Калькулятор

Калькулятор для мобильного телефона: ставится на главный экран и открывается
как отдельное приложение (PWA). Сервер на Node.js запускается из **Git CMD** на
компьютере, а телефон вычисляет через его HTTP-роуты. Внешних зависимостей нет.

Поддерживается: `+ - * / % ^`, скобки, унарный минус, дробные числа (`1.5` или `1,5`).
Выражения разбираются собственным парсером, `eval` не используется.
Если сервер недоступен, приложение считает прямо на телефоне тем же кодом.

## Требования

- [Git for Windows](https://git-scm.com/download/win) (в нём есть Git CMD)
- [Node.js](https://nodejs.org/) 18 или новее

## Запуск из Git CMD

```cmd
git clone https://github.com/yakov01vagner-png/calc.git
cd calc
start.cmd
```

Сервер напишет адреса, например:

```
Калькулятор запущен: http://localhost:3000
Откройте на телефоне (он должен быть в той же Wi-Fi сети):
  http://192.168.1.5:3000
```

Остановить сервер: `Ctrl+C`. При первом запуске Windows может спросить про доступ
Node.js к сети. Разрешите доступ для частных сетей, иначе телефон не подключится.

## Установка на телефон

1. Подключите телефон к той же Wi-Fi сети, что и компьютер.
2. Откройте на телефоне адрес из консоли, например `http://192.168.1.5:3000`.
3. Добавьте на главный экран:
   - **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   - **iPhone (Safari):** кнопка «Поделиться» → «На экран Домой».

На главном экране появится иконка «Калькулятор». На iPhone она открывается во весь
экран, без адресной строки.

На Android полноценная установка (во весь экран и с работой без сети) требует
HTTPS. По обычному `http://192.168...` Chrome добавит ярлык, который откроется во
вкладке браузера. Чтобы получить полноценное приложение при локальном запуске:
откройте на телефоне `chrome://flags/#unsafely-treat-insecure-origin-as-secure`,
впишите туда адрес сервера (например `http://192.168.1.5:3000`), включите флаг,
перезапустите Chrome и повторите шаг 3.

Индикатор вверху приложения показывает, откуда берётся ответ: зелёный — через роут
сервера, оранжевый — сервер недоступен и расчёт идёт на телефоне.

На компьютере приложение открывается по адресу http://localhost:3000.

Вместо `start.cmd` можно использовать `npm start`. Другой порт: `set PORT=8080 && start.cmd`.

### Роуты

| Метод | Роут | Описание |
|-------|------|----------|
| GET  | `/` | Приложение-калькулятор |
| GET  | `/calc?expr=<выражение>` | Вычислить выражение |
| POST | `/calc` с телом `{"expr": "2+2*3"}` | Вычислить выражение (JSON) |
| GET  | `/health` | Проверка работы сервера |

Прямо из Git CMD (в другом окне, пока сервер запущен):

```cmd
curl "http://localhost:3000/calc?expr=(2%2B3)*4"
curl -X POST http://localhost:3000/calc -H "Content-Type: application/json" -d "{\"expr\": \"2^10\"}"
```

Ответ: `{"expression":"(2+3)*4","result":20}`, при ошибке — код 400 и `{"error": "..."}`.
В строке запроса `+` нужно писать как `%2B`.

### Консольный режим

```cmd
calc.cmd "2+2*3"
calc.cmd
```

Без аргументов открывается интерактивный режим, выход — `exit`.

В Git Bash, Linux или macOS: `./start.sh` или `node src/cli.js "2+2*3"`.
